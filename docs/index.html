How it works

Three moving parts, all on your computer.

1

DNS redirect

When a PS4 tries to connect to a Minecraft featured server (The Hive, CubeCraft, etc.) it asks DNS for the IP. This tool answers your IP instead.

2

Bedrock relay

The PS4 connects to your machine. A lightweight relay accepts the Bedrock handshake and sends a Transfer packet pointing to your real Geyser server.

3

Web UI

A local HTTPS dashboard lets you change the target server without touching config files or restarting anything.

Step-by-step setup

Takes about 5 minutes.

💻

1 — Install Node.js

Download and install Node.js LTS if you don't have it. Run node -v in Terminal to check — any version 18+ is fine.

📦

2 — Download this project

Click Download ZIP above, unzip it, then open Terminal and navigate into the folder:
cd ~/Downloads/Claude-test-main

⚙️

3 — Install dependencies

In the same Terminal window run:

npm install
🚀

4 — Start the server

Run it with admin permissions (needed for port 53 and 443):

sudo node server.js

You'll see a local HTTPS link appear in the Terminal — open it in your browser. Your browser will warn about the certificate; click Advanced → Proceed. That's normal.

🎮

5 — Configure your PS4

On the PS4:

  1. Settings → Network → Set Up Internet Connection
  2. Choose Wi-Fi or LAN → Custom
  3. IP Address: Automatic
  4. DHCP Host Name: Do Not Specify
  5. DNS Settings: Manual
    • Primary DNS: (your computer's IP — shown in the web UI)
    • Secondary DNS: 8.8.8.8
  6. MTU: Automatic  |  Proxy: Do Not Use → Save
✅

6 — Join!

Open Minecraft on the PS4 → Play → Servers → tap any featured server (doesn't matter which one). You'll land on your server instead.

To undo it later, go back to PS4 network settings and switch DNS back to Automatic.

Requirements

🖥
A computer that stays on

Mac, Windows, or Linux. Must be on and connected while friends are playing.

🌐
Same network

Your computer and the PS4 must be on the same Wi-Fi or home network.

⚙️
A Geyser server

You need a Java Edition server running GeyserMC (lets Bedrock players join Java servers).

📦
Node.js 18+

The runtime that powers this tool. Free download at nodejs.org.
