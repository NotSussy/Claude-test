PS4 Setup Guide

Follow these steps on your friend's PS4. You only need to do this once.

  1. Open PS4 Settings

    From the home screen go to Settings → Network → Set Up Internet Connection.

  2. Choose connection type

    Select Use Wi-Fi or Use a LAN Cable depending on how the PS4 is connected.

  3. Select Custom

    Choose Custom (not Easy) so you can manually set the DNS.

  4. Keep IP Address on Automatic

    Leave IP Address Settings set to Automatic.

  5. Set DHCP Host Name

    Choose Do Not Specify.

  6. Set DNS to Manual

    Change DNS Settings to Manual, then set:

    • Primary DNS: see "Your Server's IP" above
    • Secondary DNS: 8.8.8.8
  7. Finish the setup

    Leave MTU as Automatic and Proxy Server as Do Not Use. Save and test the connection (it may warn — that's fine).

  8. Open Minecraft Bedrock

    Launch Minecraft on the PS4 and go to Play → Servers. You'll see the Featured Servers list.

  9. Join any Featured Server

    Tap any featured server (e.g. "The Hive", "CubeCraft", etc.). Our DNS will redirect it to this machine, which immediately transfers the player to your actual Geyser server.

Tip: To undo the redirect later, just go back into PS4 Network Settings and change DNS back to Automatic.
